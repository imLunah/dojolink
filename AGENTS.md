Please try again."` means the request was malformed, NOT that the credential was wrong.** It is the same string a bogus account gets, which makes a wrong encoding and a wrong password indistinguishable, and is why this was misdiagnosed three times. Incorrect email and / or password", "Incorrect 6-digit code". **Calibrating against a fake account proves nothing** — a malformed request and a rejected login look identical. - **How the task board works (read from source this session, and it replaced the sticky notes board):**
  1. `TasksPage` holds the whole board in one array and every mutation is optimistic with rollback. `TaskBoard` is always handed the WHOLE board, because `moveTask` restamps position across every column — a subset would renumber what it could see and scramble what it could not.
  2. **Reorder drag (≥1280px only).** Geometry is snapshotted ONCE at the moment a press becomes a drag: column rects, and each card's midpoint recorded where it WILL be once the lifted card's slot closes. Re-measuring per pointermove reads rects mid-animation and the target flickers. The held card leaves the list and is drawn in a portal overlay, moved by writing `transform` to the node — a setState per frame would re-render the board.
  3. **Swipe (everywhere the drag is not).** Document-level pointer listeners, axis-locked: horizontal past 8px wins, a vertical commit hands the gesture back to the page. `touch-action: pan-y` keeps vertical scrolling native, and Layout's own tab-swipe stands off anything marked `data-no-swipe`.
  4. **Deleting.** Swipe (armed by a hold), or drag into the band past the last column. Both call the same soft delete. The band, the goo blobs and the hit test all read one snapshot taken at drag start.
  5. **Landing.** A card that arrives in a column — dropped, moved by arrow, or swiped — plays a settle: siblings switch to an overshoot curve for ~480ms and the arriving card runs the `taskLand` keyframe, because it is a fresh mount with no previous position to animate from.
- **How MyStudio was reverse engineered, and how to redo it from scratch (session 42).** MyStudio has no public API, no OAuth, no MCP server and no service credential. Everything below was executed against the live app and returned real data. Redo this whenever an endpoint stops answering, because the vendor can rename anything without notice.
  1. **Log in.** `https://codeninjas.mystudio.io/login?goTo=%2Fhome`. Email + password, then a **6-digit code emailed to the account**, so login cannot be automated headlessly. Tick "Remember for 30 days". Each failed attempt invalidates the previous code, so a one-shot script that logs in and dies cannot complete the 2FA: hold the browser session open, or reuse the profile's existing cookies.
  2. **Enumerate the API surface from the bundles.** It is a Next.js app. From a signed-in page, collect every `script[src]` plus `performance.getEntriesByType('resource')` matching `_next/static/chunks/*.js`, fetch each, and regex for `/api/`.   3. **Find the header contract.** Chunk `7383a061fcbad5b3.js` holds `ts.create({baseURL:"/api"})` plus a request interceptor that attaches `x-origin-url`, `User-Agent-Info` and `X-User-Info` (a JSON blob built from `localforage` IndexedDB values: `active_company_id`, `stripe_account`, `user`). **Tested: only `companyId` is required.** `stripeAcc`, `userId`, `userEmail` and `isStaffRequest` are ignored by the read endpoints, so nothing has to be scraped out of IndexedDB.
  4. **Understand the auth.** Cookies, not tokens in a header. `companyId` selects the center and is itself a cookie. **`kc_access` + `kc_refresh` are httpOnly Keycloak tokens and ARE the credential.** `document.cookie` cannot see them, so a console-copied cookie looks complete and fails with `{"status":401,"error":"no_refresh_token"}`. `PHPSESSID` + `ms_u_em` belong to a LEGACY session that expires on its own schedule while the Keycloak tokens stay valid, so they must be treated as optional. `kc_access` also rotates out on its own; a cookie carrying only `kc_refresh` still works, which is why `readCookieIdentity` accepts either.

### 6. HOW TO THINK ABOUT THIS PROJECT

1. **Core architectural pattern.** A monorepo Express backend plus a Vite SPA deployed as Vercel serverless. Sessions in PostgreSQL, not JWT. `activeLocationId` on the session is the axis every permission turns on: managers switch it for read-only, `requireOwnLocation` blocks cross-center writes, `admin` bypasses everything. Supabase is used for Storage ONLY (not Auth, not PostgREST) — all DB access goes through a direct `pg` pool on the server, and storage is server-mediated via the service_role key so the client never touches it. On the frontend the equivalent philosophy is that surfaces own their appearance and shared components adapt to them, not the reverse — that instinct produced `lib/surfaces.js`, the single global focus ring, and session 39's `bare` editor variant.

2. **Most common mistakes.** (a) Forgetting `admin` must be included alongside `manager`: use `['manager','admin'].includes(req.session.role)` server-side and the same client-side. This caused bugs in sessions 2, 3 and 4. (b) Assuming a Tailwind background class means what it says: `.dark .bg-white` is a global override, so any nested `bg-white` goes dark in dark mode regardless of what it sits on, and `bg-white/80` escapes the override and stays light. Both failure modes have now bitten this project (session 28's opacity variants, session 39's nested card). On colored surfaces use inline hex or `currentColor`. (c) Never nest `MemoryRouter` inside `BrowserRouter` (React Router v6 invariant), and never use `getPublicUrl()` for Supabase Storage (buckets are private; always signed URLs).

3. **Looks wrong, intentionally stays:**
   - **The sticky note delete confirm keeps its word while everything around it is a glyph.** Reversible actions get icons; destructive confirms get language.
   - **Slot maths instead of hit-testing** in the sticky board — reading sibling rects mid-animation makes the order flicker.
   - **`useMotionValue` instead of state** for drag position — state re-renders the whole board every frame.
   - **`STICKY_MD` duplicates most of `MARKDOWN_COMPONENTS`** — the pinned-note map hardcodes amber, which would clash with five sticky palettes. Both keep `img: () => null`.
   - **`CurriculumContext` module-level `_cache`** — intentional; `invalidateCurriculumCache()` exists for admin edits. Don't swap for React Query.
   - **`AdminNav` duplicated across 4 admin pages** — leave it.
   - **`TAB_LAZY_MAP` must be static** (Vite code splitting needs statically analyzable import paths).
   - **App shell `fixed inset-0` on mobile** — prevents the iOS URL bar from shifting the viewport during swipes.
   - **MobileNav `position: absolute`, NOT `fixed`** — `fixed` triggers an iOS GPU compositing bug where the nav disappears when siblings animate.
   - **Framer Motion owns the CSS `transform` property** — don't put Tailwind transform utilities on `motion.*` elements.

✅ HIGH CONFIDENCE — points 1 and 2 verified against this session's own bug; point 3 verified by reading the files.
